# Backlog

The ideas in this backlog are not yet implemented, suggested and prone to discussion.

## 1. Bulk operations over runners

There could be an option (shift + keys, ctrl + click, etc.) to select multiple runners and perform bulk operations over them, like starting, stopping, or deleting them, with extra warning acceptance.

## 2. Recreation operation for runners

There could be an option to recreate a runner, which would delete the current one and create a new one with the same configuration. This could be useful for refreshing runners that are not working properly or have become outdated.
